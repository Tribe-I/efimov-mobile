# Командометр (мобильное приложение)

Мобильная версия «Командометра» — интерактивного опроса самооценки процессов
управления командой: 13 вопросов по мотивам матрицы «Sierra — Развитие»
(церемонии, Confluence, Jira, планирование, люди). Каждый вопрос — пять вариантов
от «вайб» до «автопилот». Балл (0–10) и «титул» уровня процессов считаются
на устройстве, дашборд обновляется после каждого ответа.

Это перенос лендинга [efimov-komandometr](https://github.com/Tribe-I/efimov-komandometr)
(живёт на <https://tribe-i.ru/efimov/landing/>) в мобильное приложение на
**React Native + Expo** (задание 10 трека AI-коучинга).

## Обещания

Приложение даёт те же пять проверяемых обещаний, что и лендинг:

1. **Название.** В шапке приложения есть видимая фирменная плашка
   «Командометр · самооценка для руководителя», а на экране «О приложении»
   название — «Командометр». (В браузерной версии обещание также требует,
   чтобы заголовок вкладки начинался со слова «Командометр»; у мобильного
   приложения вкладок браузера нет, поэтому проверяется плашка и название.)
2. **Структура опроса.** В опросе ровно 13 вопросов: первая карточка
   пронумерована «1 / 13», в дашборде счётчик «Отвечено 0 из 13» до старта;
   в каждом вопросе ровно 5 видимых вариантов ответа с непустым текстом.
3. **Честный балл.** После ответа на все 13 вопросов в дашборде появляется
   итоговый балл в формате «X.X / 10» и «титул» уровня. Титул всегда
   соответствует показанному баллу: ниже 2.5 — «ВАЙБ», 2.5–4.9 — «КАРКАС»,
   5.0–7.4 — «ШТУРВАЛ», 7.5–8.9 — «КРЕЙСЕР», 9.0 и выше — «АВТОПИЛОТ».
   Маркер шкалы стоит на отметке, соответствующей показанному баллу. Если
   везде выбрать одинаковый вариант от слабейшего к сильнейшему, пары
   балл/титул идут строго 0.0 «ВАЙБ» → 2.5 «КАРКАС» → 5.0 «ШТУРВАЛ» →
   7.5 «КРЕЙСЕР» → 10.0 «АВТОПИЛОТ».
4. **Перезапуск.** Кнопка «Пройти заново» полностью сбрасывает опрос:
   балл снова «—», счётчик «Отвечено 0 из 13», выбор с вариантов снят,
   итоговый блок скрыт, а «титул», описание уровня, вердикт и маркер шкалы
   возвращаются в исходное состояние.
5. **Приватность.** Приложение не делает сетевых запросов: ни при загрузке,
   ни при прохождении опроса не обращается к внешним адресам и ничего никуда
   не отправляет. Кнопка «Открыть веб-версию» на экране «О приложении»
   вызывает внешний браузер телефона — само приложение по сети не ходит.

## Как запустить локально

Требуется Node.js (LTS) и npm. Из корня репозитория:

```sh
npm install        # один раз: ставит зависимости
npm start          # запускает Metro (dev-сервер Expo)
```

В терминале появится QR-код:

- **Android:** отсканировать QR-код из приложения Expo Go
  (Google Play), телефон и компьютер должны быть в одной сети;
- **iPhone:** навести камеру телефона на QR-код — откроется Expo Go.

Другие команды: `npm run android`, `npm run ios` (через эмулятор),
`npm run web`. Проверка типов: `npx tsc --noEmit`.

## Экран «О приложении» и хеш сборки

Экран «О приложении» показывает короткий хеш коммита, из которого собрано
приложение. Хеш берётся из переменной окружения `EXPO_PUBLIC_COMMIT`; если она
не задана (локальная разработка), вместо хеша показывается `dev`. В коде хеш
не хранится.

## Структура

| Путь | Что это |
| --- | --- |
| `App.tsx` | Корень: переключение экранов «Главная» / «О приложении» кнопками (без библиотек навигации) |
| `src/screens/HomeScreen.tsx` | Опрос и дашборд целиком |
| `src/screens/AboutScreen.tsx` | Экран «О приложении»: название, фраза, хеш сборки, ссылка на лендинг |
| `src/data/questions.ts` | 13 вопросов и варианты ответов (дословно с лендинга) |
| `src/data/levels.ts` | Пять уровней: границы баллов, титулы, описания, советы |
| `src/theme.ts` | Фирменные цвета и шкала из лендинга |
| `assets/` | Иконки и сплэш-экран приложения |

## Как предложить изменение

1. Создайте ветку от свежей `main`: имя `<логин>/<суть>`.
2. Проверьте локально: `npm start`, пройдите опрос до конца в Expo Go.
3. Откройте PR в `main` с описанием: что изменено, как проверить.
4. Прямых коммитов в `main` нет (исключение — стартовая фиксация проекта).

базовые компоненты.
